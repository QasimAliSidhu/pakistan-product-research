# Try Pakistan Product Research

## Start here

Clone this repository and open a terminal in its root. All examples below use fictional inputs.

For the offline calculation, install `numpy`. For the full workspace, install `requirements.txt` and follow the README. The example makes no marketplace requests.

```console
python examples/cost_scenario.py
```

## A useful exercise

Change return_pct from 10 to 20 in the fictional input file and compare the expected contribution. Keep the fee and supplier assumptions unconfirmed until you have evidence.
