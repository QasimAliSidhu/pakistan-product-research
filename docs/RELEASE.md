# Pakistan Product Research — public demo

Try the sample calculator, then change price or return rate. Watch both contribution and cash requirements before deciding whether a product deserves more research.

## Try it

```console
python examples/cost_scenario.py
```

[Pakistan Product Research quick-start guide](https://github.com/QasimAliSidhu/pakistan-product-research/blob/main/docs/QUICKSTART.md)

Change return_pct from 10 to 20 in the fictional input file and compare the expected contribution. Keep the fee and supplier assumptions unconfirmed until you have evidence.
